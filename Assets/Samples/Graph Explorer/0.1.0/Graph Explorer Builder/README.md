# Graph Explorer Builder

Import **Graph Explorer Builder** from Package Manager's Samples section, then
open `GraphExplorerBuilder.unity` and enter Play Mode. The scene creates a small
network on startup and builds its controls at runtime.

Use **Create graph** to generate a repeatable network from node count, edge
density, and seed. The Nodes and Edges sections add, edit, select, and remove
records. Clusters can be collapsed, expanded, hidden, or removed. Regions support
nested membership, boundary and content visibility, bounds, and local physics.
Rendering and Physics settings update the current session live. Physics defaults
match the package force solver's original values.

The camera uses the active project's Universal Render Pipeline asset. Drag with
the left mouse button to orbit, right or middle drag to pan, and scroll to zoom.
