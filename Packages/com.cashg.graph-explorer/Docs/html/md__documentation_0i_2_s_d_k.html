Graph Explorer SDK

Reference for developers and AI agents, matching package 0.1.0 and the checkpoint-4 standalone consumer. For a generated catalog of every public type and member, see ARCHITECTURE.md. The checked-in declarations linked below are authoritative when signatures change. Snippets are integration fragments. The complete consumer is Northstar Robotics.

1. Scope and feature status

Area Available now Host responsibility / limits
Data Stable dataset/node/edge IDs, directed typed relationships, scalar metadata, provenance, confidence, adjacency indexes, atomic batches/snapshots, deterministic JSON Import/normalize facts; assign stable IDs and relationship meaning
View Positions, velocities, pins, selection/focus, visibility, favorites, emphasis; deterministic initial positions; reversible nested clusters and distance LOD Own interaction/state persistence and cluster controls
Layout Force-directed spatial/flat layouts; group constraints and ordered lanes Supply grouping/lane policies; layout proximity is not evidence of a relationship
Rendering Instanced node shapes, dynamic edge ribbons, picking, context highlighting, toon/outline/glow effects, atmosphere Supply camera/URP setup, input routing and frame scheduling
UI Resizable responsive shell, scale/reduced motion, fuzzy node search, favorites, schema inspector, relationship search/highlight, filter controls, labels/markers Compose panels/bindings; dataset filters, custom forms, source actions and persistence remain host policy
Actions Definitions/targets, review, ordered submission, recovery/control/progress contracts; generic row/reorder presentation Provider executes and owns authoritative state; host owns draft and durable pending identity
Storage Version-checked, scoped JSON, atomic replacement, copy-only legacy migration Define versioned DTOs and migration policy; no automatic workspace serialization
Diagnostics Resource/graph Editor validation, profiler markers, fixture/test utilities Run checks appropriate to the consuming project

Not implemented yet: general hierarchy forest derivation/layout, the optional multi-language com.cashg.graph-explorer.codebase package, or expanded scale/platform guarantees. The standalone CodebaseGraph host provides C# semantic ingestion and Git revision exploration; Python/JS/TS ingestion is not available. The standalone org-chart project demonstrates clean consumption and explicit instance/lifecycle validation; see its evidence for the precise tested limits. This is a composable SDK; there is no single component that builds a complete explorer application for an empty host.

Use Package Manager Add package from disk with package.json. The current repository host uses this entry in Packages/manifest.json:

"com.cashg.graph-explorer": "file:../../../packages/com.cashg.graph-explorer"

3. Model terminology and rules

Type Meaning / main API
GraphValue / GraphValueType From(string/double/bool), Null; finite scalar values only
GraphNodeRecord Immutable Id, TypeId, Label, Properties, Sources; WithIdentity, WithProperty, WithSources return replacements
GraphEdgeRecord Immutable Id, From, To, TypeId, Status, optional Confidence, metadata/sources; WithEvidence returns a replacement
GraphDocument Canonical facts and temporal history: Nodes, Edges, UpsertNode, UpsertEdge, removals, Apply, ReplaceSnapshot, EstablishBaseline, event/time Seek, ReturnToLive, Timeline, RecordPositionFrame, ClearPositionHistory, ClearEventHistory, ClearHistory, adjacency queries
GraphBatch Mutable transaction input: Nodes/Edges upserts, RemoveNodes/RemoveEdges IDs
GraphSnapshot Dataset identity/display name plus complete record lists
GraphSchema Registers descriptors and Validate(document); validation returns issues
GraphViewState / GraphNodeViewState Separate per-instance presentation state; GetOrCreate, Synchronize, SelectedId, FocusId, FoldedNodeIds
GraphPathfinder / GraphPathState Directed unweighted shortest paths, persistent endpoints/results, graph-pick requests and topology refresh
GraphRevisionTimeline / GraphRevision Host-imported discrete revisions, parent IDs, optional source timestamps, branch lane connections, readiness and confirmed selection; snapshots remain provider-owned
GraphScene Default live IGraphScene projection over document/schema/view; call Synchronize() after document mutation
GraphClusterScene Optional IGraphScene wrapper for nested temporary clusters, crossing-edge rewiring, and camera-distance LOD; source facts remain intact
IGraphNode / IGraphEdge Live facade over records and view state; implement these for richer domain adapters

IDs are nonempty, case-sensitive ordinal strings; no implicit deduplication or normalization occurs. Self-links, parallel edges, reversed edges and cycles are valid. Distinct-neighbor degree ignores direction/parallel edges and excludes self-links. Confidence must be finite if supplied; its scale is dataset-defined.

Records copy their input collections. WithProperty(key, null) removes a property; WithProperty(key, GraphValue.Null) stores explicit null. Nested metadata is not supported; encode timestamps as text and keep structured provider data separate.

Edges require existing endpoints. Apply validates before committing, supports forward references within the same batch and removes incident edges with removed nodes. Contradictory/duplicate operations or dangling endpoints reject the whole batch. ReplaceSnapshot validates a detached replacement and requires the same dataset ID. Use a new document/view/scene for a different dataset.

Revision tracks semantic changes; TopologyRevision tracks structure/type changes. View edits change neither. GraphScene.Revision exposes topology revision. Preserve projection identity; do not copy an entire graph each frame. Reacquire adjacency handles after snapshot replacement or node deletion/recreation.

The model is single-threaded: load/analyze elsewhere, then apply on the owner thread. Snapshot work is O (V+E); neighborhood traversal visits reached topology.

Reversible neighborhood clustering

Wrap an existing scene and pass the wrapper to layout, renderer, picking, and any UI that should show clusters. The document stays authoritative; projected edges keep their original IDs, direction, type, properties, and sources. Edges entirely inside a collapsed cluster are hidden, then restored on expansion. Parallel crossing edges stay separate. LeafIds, MemberRecords, and InternalEdges resolve source facts across every nesting level, so application actions can target real entities and an inspector can show the cluster contents.

var clustered = new GraphClusterScene(scene);
string team = clustered.Collapse(new[] { "lead", "dev" }, "Team");
string division = clustered.Collapse(new[] { team, "designer" }, "Division");
layout.Bind(clustered);
renderer.UpdateMetrics(clustered, edgeFilter);
// On an expand action, the first call reveals the nested Team cluster.
clustered.Expand(division);
layout.Bind(clustered);
// Expand Team to reveal lead and dev with their original edges.
clustered.Expand(team);
layout.Bind(clustered);

Collapse accepts visible nodes or existing clusters that share an immediate parent. A host can call it from its domain logic. Recollapse retains a saved group; RemoveCluster dissolves the group. Moving a collapsed cluster shifts its children by the same amount when expanded. Cluster IDs are temporary view IDs; save the member IDs and domain rule if a host needs persistent groups.

For automatic distance LOD, set LodEnabled = true and call UpdateLod(camera.transform.position) at a modest interval. It groups connected nodes whose positions are within LodNeighborSeparation, after they pass LodEnterDistance; it releases automatic groups inside LodExitDistance. Keep exit below enter for hysteresis. Rebind layout and update renderer metrics when the method returns true. Manual clusters remain under application control. Expanding an automatic cluster suppresses automatic regrouping of its members; call ClearLodOverrides() to let distance LOD group them again.

Shortest paths

Shortest paths follow directed From → To edges and count each eligible loaded edge as one jump. Breadth-first search orders adjacent destinations and edge IDs ordinally so equal-length routes are deterministic. UI visibility filters and edge metadata do not change traversal cost. The optional Func<IGraphEdge, bool> edgeAllowed argument on GraphPathfinder.Find and GraphPathState restricts eligibility without changing the canonical document or default behavior.

var path = new GraphPathState(scene);
var renderBinding = GraphPathRendering.Bind(path, renderer);
path.Show("employee:1", "company:9"); // active route, or an active no-path result
path.Synchronize(); // after scene topology synchronization
path.BeginPick(GraphPathEndpoint.Start);
// In the host's primary-click handler, consume endpoint clicks before selection:
bool used = GraphSceneInput.HandlePathPick(hoverSample, path);
path.Clear(); // dismiss and restore ordinary highlights
renderBinding.Dispose(); // on host teardown

A code consumer can use new GraphPathState(scene, edge => edge.Relation == "calls" || edge.Relation == "uses_type") to exclude structural shortcuts. The predicate remains in effect across Bind and topology refreshes. Call Synchronize(true) when a predicate closes over policy that changes without a topology change. Pathfinding should use the canonical scene; reveal route symbols through a cluster projection before rendering their original IDs.

GraphPathState.Changed reports endpoint, route and active-state changes. Result.NodeIds and Result.EdgeIds preserve order; Jumps is edge count and the same-node route has zero jumps. After topology changes, synchronize the scene and call path.Synchronize(); endpoints remain active and the result is recomputed, including an unreachable result if the route no longer exists.

GraphPathPresenter builds the compact UI Toolkit window. Pass it the root overlay, scene, path state, a navigation callback, and optionally a pick callback (the default requests picking from the state). Check GraphSceneInput.HandlePathPick before ordinary node selection so endpoint clicks do not replace selection. Dispose the presenter when removing the panel. Selecting a route row invokes the supplied navigation callback. The optional final nodeLabel callback formats endpoint choices and route rows for domains with duplicate short labels, such as qualified code symbols.

Imported revision graphs

GraphTimeline records one document's ordinary event/motion stream. Source-control branches instead use GraphRevisionTimeline: it accepts an ordered collection of GraphRevision(id, parentIds, timestampUtc, label). Supply parent-before-child topological order. Source timestamps are optional and descriptive; they do not determine seek order and need not be monotonic. A working copy can use a null timestamp.

var revisions = new GraphRevisionTimeline();
revisions.Replace(new[] {
new GraphRevision("commit-a", Array.Empty<string>(), commitTime, "Initial"),
new GraphRevision("working", new[] { "commit-a" }, null, "Working Tree")
});
revisions.SelectionRequested += revision => RequestSnapshotFromProvider(revision.Id);
// After the provider succeeds and the host displays its validated snapshot:
revisions.MarkReady("commit-a", GraphRevisionChangeSummary.Between(null, snapshot));
revisions.ConfirmSelection("commit-a");

Replace validates revision IDs before changing the active collection. RequestSelection asks the host to load a revision; ConfirmSelection only follows successful display, so a failed load can retain the old graph. Changed reports metadata/readiness/selection changes. Lane, LaneCount, and LaneLinks describe connections for rows displayed newest first; hosts draw parent/merge lanes and own scrubbing, playback, progress, cancellation, source opening, and snapshot caching. Revision descriptors do not retain full graph snapshots and are not serialized by GraphJson.

GraphRevisionChangeSummary.Between(before, after) returns ordered created, modified, and deleted node/edge IDs and counts. Symbols with a content_hash property use that fingerprint for modification checks, ignoring source-line movement. Other nodes compare type/label; edges compare endpoints, relation, status, confidence, and scalar properties. The host defines the comparison parent (CodebaseGraph uses first-parent diffs). Do not turn jumps between branch snapshots into invented timestamped document events. The complete C# integration is in GraphExplorer.CodebaseGraph.

4. Schema, appearance and layout

  • GraphNodeTypeDefinition: type label, ShapeId, color and positive default radius.
  • GraphFieldDefinition: type, label, Searchable/Inspectable, unit, PartitionBy, optional category dictionary. Undeclared fields are allowed.
  • GraphCategoryDefinition: label, color, badge and order.
  • GraphRelationDefinition: label/color, spring strength and hierarchy direction. ParentIsFrom=false means the edge's To endpoint is the parent.
  • Registration uses unique IDs; duplicate registrations throw rather than replace.

Built-in shape IDs: Briefcase, Building, Badge, Factory, Gear, Person, MapPin, Globe, Document, Gem. Missing shapes fall back to Gem; unknown node types get a neutral presentation descriptor.

GraphPresentationProfile selects MetricField/CategoryField, optional applicability predicates and category fallback/metric color functions. Numeric ranges are computed per field-defined PartitionBy value, avoiding comparisons across incompatible units. Grouping uses IsGroupAnchor, GroupId, GroupStrength; lanes use Lane, LaneCenter, LaneSpacing. Configure policies before binding the layout.

var profile = new GraphPresentationProfile { MetricField = "tenure" };
// session is initialized in the next section.
session.Layout.Mode = LayoutMode.Flat; // Spatial, Flat, Groups, Lanes
session.Renderer.Size = SizeMapping.Metric; // Uniform, Connections, Metric
session.Renderer.ColorBy = ColorMapping.Type; // Type, Connections, Category, Metric
session.Layout.Reheat();

5. Rendering, navigation and lifetime

Supply a host-configured camera and URP scene. Initialization validates defaults, creates owned runtime resources and attaches effects; it does not frame the camera or configure global frame rate. Keep the session alive across frames.

// Setup once, e.g. in your host's initialization method:
var resources = new GraphResourceConfiguration();
var options = new GraphExplorerOptions(nodeRenderBudget: 8000, nodeLabelBudget: 48);
var session = GraphRenderingSession.Initialize(camera, resources, profile, options);
session.Layout.Bind(scene);
IGraphEdgeFilter edgeFilter = new AllEdges();
session.Renderer.UpdateMetrics(scene, edgeFilter);
session.Navigation.Overview(scene); // Explicit host request to move the camera.
// Each host frame; selected/hovered references may be null:
session.Layout.Step(Time.deltaTime);
session.Navigation.Tick(inputBlocked, selected);
session.Atmosphere.Tick(reducedMotion);
session.Renderer.ReducedMotion = reducedMotion;
session.Renderer.Draw(scene, edgeFilter, camera, selected, hovered, hoveredEdge);
// Teardown, after stopping host coroutines and disposing UI presenters:
session.Dispose();
// Declare this helper separately in your consumer:
sealed class AllEdges : IGraphEdgeFilter {
public bool EdgeMatches(IGraphEdge edge) => true;
}

Ownership and resources

One active rendering session per camera. Dispose is idempotent and releases owned meshes/materials, effects, atmosphere, render subscriptions and cursor capture; borrowed camera/effect state is restored where managed by the session. Camera, document/schema, source resource assets and host UI roots remain host-owned.

Defaults load from Resources/CashgGraphExplorer/ using GraphResources.Load<T>(key). Per-instance overrides use resources.Set(key, asset); model keys are GraphNodeModels/<ShapeId>. Settings/assets include GraphVisualSettings, GraphNodeLabelSettings, GraphPanelSettings, GraphTheme, GraphExplorer and GraphShell styles. Clone mutable ScriptableObject/PanelSettings assets per host; do not edit package defaults to change one explorer instance.

GraphNodeLabelSettings enables mouse-proximity title reveal by default. The shared world-label presenter measures from each node's projected center to the mouse in screen pixels (independent of UI scale), with full opacity inside RevealInnerRadius (40 px) and a smooth falloff to zero at RevealOuterRadius (180 px). RevealFadeSeconds (0.15 s) controls unscaled fade timing. Moving over UI, outside the graph viewport, or out of the focused application fades labels away. KeepSelectedLabelVisible preserves the selected title; disable it for strict proximity visibility. The entire label panel fades together. Host distance LOD/opacity, label budgets and overlap avoidance still apply. Set MouseProximityReveal to false to restore the original host visibility policy.

7. Dataset providers

IGraphDataProvider.Identity identifies the source. Load(datasetId, progress, cancellation, completed, failed) returns a GraphSnapshot; call it again to refresh. LoadDetails(datasetId, nodeId, ...) returns a GraphBatch.

Both return IEnumerator: run them on your host coroutine runner. Completion/error callbacks must occur once on the owning thread. GraphProviderProgress contains message and optional fraction 0..1. Providers should honor cancellation; the interface does not abort IO automatically. Cancel/stop owned operations on teardown.

Apply a successful same-dataset snapshot with ReplaceSnapshot, then synchronize scene/rebind layout/refresh metrics and UI. On failure/cancellation, retain the last valid graph. The contracts do not automatically load, swap documents or render UI. Job Harvester's adapter wraps its existing loading/application pipeline; do not copy that domain controller into a new generic consumer.

Queue lifecycle:

  1. Resolve candidate targets and let users choose ambiguous/group targets. Capture stable bindings; do not infer ownership from spatial proximity.
  2. Keep an ordered host draft; review with queue.Review(draft, token, completed, failed). The coordinator snapshots list order, not a deep immutable copy of requests.
  3. Lock edits while reviewing/submitting. Invalidate review after any draft change.
  4. Call queue.Submit(review, persistPending, token, completed, failed). The synchronous Func<bool> must durably save review.Id, ReviewToken and provider identity; false prevents execution. It must not throw for an ordinary save failure.
  5. Provider execution must reject stale/changed reviews and be idempotent for that same run ID. After uncertain completion retain pending identity and reconcile with Recover; do not create a new submission ID or assume success/failure.
  6. Refresh authoritative progress/history. Control(runId, operation, entryId, ...) uses provider-defined operations; pass null entry ID for run-level control.

Coordinator inputs/callbacks must be non-null and well formed. It does not own persistent drafts, clear them, poll automatically, validate domain prerequisites, choose targets or execute worker semantics. Opaque payloads preserve nested provider configuration and richer worker progress. Clone JsonElement values borrowed from a JsonDocument before disposing it.
