IDs are nonempty, case-\/sensitive ordinal strings; no implicit deduplication or normalization occurs. Self-\/links, parallel edges, reversed edges and cycles are valid. Distinct-\/neighbor degree ignores direction/\+parallel edges and excludes self-\/links. Confidence must be finite if supplied; its scale is dataset-\/defined.

Records copy their input collections. {\ttfamily With\+Property(key, null)} removes a property; {\ttfamily With\+Property(key, Graph\+Value.\+Null)} stores explicit null. Nested metadata is not supported; encode timestamps as text and keep structured provider data separate.

Edges require existing endpoints. {\ttfamily Apply} validates before committing, supports forward references within the same batch and removes incident edges with removed nodes. Contradictory/\+duplicate operations or dangling endpoints reject the whole batch. {\ttfamily Replace\+Snapshot} validates a detached replacement and requires the same dataset ID. Use a new document/\+view/\+scene for a different dataset.

{\ttfamily Revision} tracks semantic changes; {\ttfamily Topology\+Revision} tracks structure/\+type changes. View edits change neither. {\ttfamily Graph\+Scene.\+Revision} exposes topology revision. Preserve projection identity; do not copy an entire graph each frame. Reacquire adjacency handles after snapshot replacement or node deletion/\+recreation.

The model is single-\/threaded: load/\+analyze elsewhere, then apply on the owner thread. Snapshot work is O (V+E); neighborhood traversal visits reached topology.\hypertarget{md__documentation_0i_2_s_d_k_autotoc_md166}{}\doxysubsection{\texorpdfstring{Reversible neighborhood clustering}{Reversible neighborhood clustering}}\label{md__documentation_0i_2_s_d_k_autotoc_md166}
Wrap an existing scene and pass the wrapper to layout, renderer, picking, and any UI that should show clusters. The document stays authoritative; projected edges keep their original IDs, direction, type, properties, and sources. Edges entirely inside a collapsed cluster are hidden, then restored on expansion. Parallel crossing edges stay separate. {\ttfamily Leaf\+Ids}, {\ttfamily Member\+Records}, and {\ttfamily Internal\+Edges} resolve source facts across every nesting level, so application actions can target real entities and an inspector can show the cluster contents.

{\ttfamily Collapse} accepts visible nodes or existing clusters that share an immediate parent. A host can call it from its domain logic. {\ttfamily Recollapse} retains a saved group; {\ttfamily Remove\+Cluster} dissolves the group. Moving a collapsed cluster shifts its children by the same amount when expanded. Cluster IDs are temporary view IDs; save the member IDs and domain rule if a host needs persistent groups.

For automatic distance LOD, set {\ttfamily Lod\+Enabled = true} and call {\ttfamily Update\+Lod(camera.\+transform.\+position)} at a modest interval. It groups connected nodes whose positions are within {\ttfamily Lod\+Neighbor\+Separation}, after they pass {\ttfamily Lod\+Enter\+Distance}; it releases automatic groups inside {\ttfamily Lod\+Exit\+Distance}. Keep exit below enter for hysteresis. Rebind layout and update renderer metrics when the method returns true. Manual clusters remain under application control. Expanding an automatic cluster suppresses automatic regrouping of its members; call {\ttfamily Clear\+Lod\+Overrides()} to let distance LOD group them again.\hypertarget{md__documentation_0i_2_s_d_k_autotoc_md167}{}\doxysubsection{\texorpdfstring{Shortest paths}{Shortest paths}}\label{md__documentation_0i_2_s_d_k_autotoc_md167}
