{\bfseries{Rules worth remembering:}}


\begin{DoxyItemize}
\item IDs are opaque, case-\/sensitive strings; no auto-\/deduplication.
\item {\ttfamily Apply} validates the whole batch; conflicting ops roll back entirely.
\item Editing while timeline is historical auto-\/returns to live ({\ttfamily Ensure\+Live}).
\item Layout proximity is not evidence of a semantic edge.
