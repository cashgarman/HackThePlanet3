All meshes use Y up, a centered bounding-\/box pivot, and a maximum vertex distance of 0.\+5 from the pivot. The graph scales them by {\ttfamily 2 \texorpdfstring{$\ast$}{*} Radius(node)}, so geometry fits the existing node radius. The selection halo has its own mesh. Picking uses a slightly larger sphere, making thin shapes and holes easy to select.

{\ttfamily Graph\+Node\+Models.\+Create} loads one imported mesh per shape and clones it once for the renderer to own. The renderer supplies white vertex colors and the existing instance tint. Each model has one submesh, so the existing batches remain one instanced draw per shape per 1,023 nodes. Models are not regenerated per frame and need no per-\/node Game\+Objects or colliders. The importer keeps CPU mesh access enabled for assigning vertex colors in player builds.

The generator uses only Python\textquotesingle{}s standard library. Its small geometry helpers expose extrusion, surfaces of revolution, and tubes directly. Edit these source dimensions to revise the set; the final normalization preserves consistent graph scale. Keep schema shape IDs aligned with the OBJ filenames and retain their {\ttfamily .meta} files. The OBJ object names remain unchanged to preserve imported subasset IDs.

In Unity, run {\bfseries{Job Harvester \texorpdfstring{$>$}{>} Validate and preview node models}}. It checks every imported mesh, renders front / three-\/quarter / rear views with the actual graph shader, and checks submission and picking through {\ttfamily Graph\+Renderer}. Results are written under the project directory\textquotesingle{}s {\ttfamily node-\/model-\/validation} folder. These checks do not measure large-\/graph frame time.
